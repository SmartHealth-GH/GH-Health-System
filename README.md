# GH-Health-System

## 📋 Project Overview
This system optimizes hospital service operations in Ghana, including:
- Service request prioritization
- Resource allocation
- Route optimization between hospital locations
- Performance analysis

## 👥 Team
- **16 Members** | **Team Lead:** [Michael Anarfo, Laurel Onny]

## 🎯 Context
**Hospital Operations** - Emergency response, patient management, ambulance dispatch

## 📚 Required Data Structures (Custom Implementation)
- Dynamic Array, Linked List, Stack, Queue, Circular Queue, Deque, Priority Queue, BST, Red-Black Tree, B-Tree, Hash Table, Set/Map, Disjoint Set, Graph

## 🧮 Required Algorithms
- Search: Linear, Binary etc
- Sort: Selection, Insertion, Merge, Quick, etc
- Graph: BFS, DFS, Dijkstra, Prim, Kruskal, etc
- Optimization: Greedy, Dynamic Programming

## 🗄️ Database
- SQLite/MySQL/PostgreSQL
- Tables: locations, roads, service_requests, resources, algorithm_runs

## 🚀 How to Run
1. Clone the repository
2. Import into your IDE (IntelliJ/Eclipse)
3. Set up database (run schema.sql)
4. Load data from CSV files
5. Run HospitalOperationsSystem.java

## 📊 Performance Experiments
- Search comparison (Linear vs Binary)
- Sort comparison (Selection, Insertion, Merge, Quick)
- Hash table load factor analysis
- BST vs Balanced tree comparison
- Graph algorithm performance
